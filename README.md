# BGFD Training Performance App

Bowling Green Fire Department Training Division personnel performance tracker.

Open the live site after GitHub Pages is enabled:

**https://nickatkinsbgky.github.io/Training/**

Data is stored in the browser (`localStorage`). Use Export JSON / Import JSON to back up or move records between computers.

## Enable GitHub Pages

1. Open the repository **Settings** → **Pages**
2. Under **Build and deployment**, set **Source** to **GitHub Actions**
   - or **Deploy from a branch** → `main` / `/ (root)`
3. Wait a minute, then visit https://nickatkinsbgky.github.io/Training/
